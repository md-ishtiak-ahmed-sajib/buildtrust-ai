# Submission package

This folder contains the prepared BuildTrust AI judge files. The app uses fictional data and simulated payments. No real bank is connected.

| File or folder | What to use it for |
|---|---|
| BuildTrustAI_Security_Self_Assessment.pdf | Readable security report with the 19-control improvement checklist and honest status labels |
| BuildTrustAI_Technical_Documentation.pdf | Readable architecture and technical guide with security diagrams |
| BuildTrustAI_Presentation.pptx | Nine slides with speaker notes; target talk length eight to nine minutes |
| BuildTrustAI_Demo.mp4 | Actual app demonstration below five minutes; local synthetic English narration is disclosed |
| BuildTrustAI_Source.zip | Source, docs, sample files and verified submission materials, without private runtime data |
| BuildTrustAI_Source.zip.sha256 | Checksum for the source archive |
| release-manifest.json | Packaged file hashes and evidence fingerprint |
| screenshots/ | Actual app screens and their source notes |
| execution-evidence/ | Test logs, HTTP examples, audit results and artifact checks |
| submission-checklist.md | Prepared items and the team's remaining submission steps |

Technical and security documents are in [the documentation index](../docs/README.md). [The README](../README.md) gives a single Windows public-demo command and all four public passwords. The public profile is separate from private local records.
